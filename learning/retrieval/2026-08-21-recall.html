Value เก็บอะไรไว้บ้าง นับให้ครบทุก field

Value เก็บอะไรไว้บ้าง นับให้ครบทุก Field แล้วก็ตัด Unway มาทำไม คือใน Neural Network เราจะสร้าง Computational Graph ใช่ไหมจากแต่ละ Node เพราะงั้นเอามาบวกกันมาคูณกันเนี่ยมันก็ต้อง เอิ่ม Value โอเคคือต้องมี Data ก็คือเป็นค่าของ Node นั้น ต้องมีอยู่แล้ว แล้วก็พอเอามาบวกกันน่ะเราก็ต้องมี Thunder App แล้วก็ Thunder Mul Mul มันจะได้เอามาบวกกันได้คูณกันได้โดยที่ไม่ต้องแบบ โดยใช้แค่ Operator ธรรมดา อย่างเช่น a+b, a*b อะไรอย่างเงี้ย ทีนี้ไอ้นั่นคืออันนั้นไม่ใช่ Field แต่ว่า อันนั้นไม่ใช่ Field แต่ว่าเป็น Method แต่ว่าไม่เป็นไร

กลับมาที่ Field เราต้องมี เอิ่ม เราต้องมี Previous เราต้องมี Previous ทำไมต้องมี Previous คือเดี๋ยวพอเราสร้างไอ Computer Graph เสร็จแล้วอ่ะ เดี๋ยวเราต้องทำ Backdrop ไง ซึ่งตอนที่เราทำ Backdrop อ่ะเราต้อง เราต้องมีลำดับของหนวดในการเรียก Underscore Backward เอิ่มซึ่งมันจะเป็นแบบลำดับไหนไม่ได้ มันต้องเป็น Topological Sort เราตอนที่เรา Sort หรือแบบย้อนกลับเนี่ยมันต้องใช้ เราต้องรู้ Node Node ก่อนหน้าเพราะมันต้องมี Previous เพราะฉะนั้น Underscore Previous นี่ใช้ในการทำ Topological Sort

โอเค แล้วมีอะไรอีก มี Gradient เออ Gradient เอ่อมี Grad เราต้องดู Grad Gradient ของแต่ละโหนดเพราะเดี๋ยวเราจะ เอิ่มหา Gradient เพราะงั้นก็หลักๆคือมี Data มี มี under_previous ซึ่งต้องเป็น ซึ่งต้องเป็น List นะหรือเปล่า ต้องเป็น List เฮ้ย หรือว่ามันเสร็จวะ คือลำดับมันสำคัญไหม มันไม่สำคัญเท่าไหร่แต่ว่าตอนที่เรา plot ออกมาเป็นกราฟอ่ะ มัน คือถ้าเกิดเราไม่มีให้ ไม่ให้มีลำดับเราก็ไม่จะรู้ว่า เราก็จะไม่รู้ว่า ก็จะไม่รู้ว่ามันไป ทางไหนก่อน เพราะงั้น List เหรอหมายถึง Data Structure ของไอ previous อ่ะนะ

ตอน a * b เกิดอะไรขึ้นบ้าง

A คูล Bแล้วมันเกิดอะไรขึ้นบ้างก็ พอ A คูล B เสร็จมันก็จะมี object ใหม่เป็น value ใหม่ก็ข้างในก็คือมันเอา data ของ A มาคูลกับ data ของ Bมันก็จะคูลใน under double underscoreเมอร์ คูณ Double Score Modification ทีนี้ เอ่อ ก็ตอนที่มันสร้าง A คูณ B อ่ะ ก็เดี๋ยว คือเอกลิมมันก็มีเกรดียนมีค่าแล้วก็มีมี Operatorคือ Operatorเน่จริงๆไม่ได้ใช้เท่าไรแต่ว่าใช้ตอนแค่พอร์ตกราซ์เฉยๆ

อื้มเพราะทิศจริงๆเราจะทำก็คือเราจะ Backward เฉยๆแล้ววิธีการ Backwardเราทำให้เป็น Courserไปแล้วคือฟังก์ชัน Backward มันเป็น closure ซึ่งมีซึ่งเก็บข้อมูลของ ของ value ของ a กับ b อยู่แล้ว เราก็เลยเรียกใช้ backward ได้เลยโดยที่ไม่ต้องแบบว่าไปอ้าง ไปอ้างอิงถึง คืออะไร ไม่ต้องไปใช้ operator แล้วก็ไม่ต้องใช้ previous อ่ะ เพราะ operator กับ previous เนี่ยมัน ฝังอยู่ในไอ function backward อยู่แล้ว ซึ่งเราสร้าง ซึ่ง function backward ของ A คูณ B อ่ะ เราสร้างตอนที่เราจับ A มาคูณกับ B

โอ้ เมื้อกี๊เหมือนตอบพ่อซามไปแล้วว่าไอ แบคเวิร์ดมันจับอะไรบ้างทีนีคำถามคือ ทำไมมันต้องทำไมมันต้องจับแล้วก็ไม่ใช่ไปอ่านไว้อืมคือถ้าจะไม่ต้องจับอะมันก็จะไปแยกเคส ว่าเฮ้ยถ้าจะเอาไปไว้ใช่เป็นคูล ต้องคำนวณอันนี้ ถ้าเกิดว่า Option เป็นบวกก็ต้องไปทำอย่างนี้ ซึ่งความแตกต่างมันคืออะไร ความแตกต่างระหว่างสองวิธีนี้คืออะไร วิธีที่ใช้ Closure กับวิธีที่แยกกรณีเป็นอีกฟังก์ชันหนึ่งแล้วแยกกรณี โอเคมันก็คือมันก็จะมีฟังก์ชันเดียวไม่ไม่มี Closure เลย

แต่คือ เอิ่ม ยังไงดี มันก็อาจจะได้ทั้งคู่นะแต่ว่าวิธีไหนดีกว่ากันแล้วมันต่างกันยังไง แต่วิธีใช้โครเชิลมันดีตรงทีมันการส่งต่อข้อมูลมันน้อยอ่ะคือพอใส่โครเชิลไปเราก็รูอะไรเล็กๆแค่แปลกกว่าแล้วมันก็จํามันก็จําว่ามันต้องไปปรับอะไรของมันได้เลยอ่ะแต่คําถามคือ เฮ้ยมันจะมีปัญหาเรือนเรือเปล่าเรายังไม่รูหรือกระดานน เพราะว่าเหมือน กับโฟสเซอร์ใส่เหมือนมันฟังข้อมูลใส่ในฟังชันอะไรอย่างเงี๊ยะก็ว่ามันเปลือกเปลืองโหม เมโมรีแค่ไหนอะไรอย่างเงี๊ยะไอ้ Memory spaceมันเป็นยังไงนึกเราไม่รูเราพายตอนมันไปเก็บข้อมูลไหนๆนะ เวลาแบบเราสร้างอย่างเงี๊ยะแบบเก็บใน RAMหรอกว่ายังไงแล้วมันเปลืองไข้ไหนมั โอเค ต่อไป

backward() ทำอะไรบ้าง เรียงให้ถูก

Backward ทำสี่อย่างเหมือนกัน คืออันนี้คือ Backprop ทั้ง Loop แล้ว เอิ่ม ก็คือตอนแรกก็คือเซต Gradient ของ Node สุดท้ายให้เป็นหนึ่งก่อน แล้วทีนี้ก็ไล่เรียก underscore backward ตาม Node ของเอ่อ Topologic Sort อัปเดต เสร็จปุ๊บอัปเดต เกรดินต์ เสร็จปุ๊บแล้วก็อัปเดต เกรดินต์ เสร็จปุ๊บแล้วก็อัปเดต เวทย์ก็ใช้เกรดินท์เหล่าเหล่าน้อยมาอัปเดตเวทย์แบบจะแบบเริ่นนิ้วเวทย์อะไรอย่างง่ายอัปเดตเวทย์เสร็จปุ๊บ สิ่งที่คนจะลืมก็คือมันต้อง Reset Gradient ของทุกตัว อืมก็ Set Gradient ของทุกตัวให้เป็นศูนย์ แล้วก็จบ พอมันเรียก Back Prop ใหม่ก็คือ Gradient สุดท้ายเป็นหนึ่ง อัปเดต Gradient ของตัวตาม Topological Sort อัปเดต Weight กับ Bias พารามิเตอร์อ่ะตาม Gradient แล้วก็ Set gradient เป็นศูนย์

Neuron → Layer → MLP ต่อกันยังไง

Neuron Layer MLP ต่อกันยังไงคือตรงน้อยท่านเจ๋งคือเราสร้างClass ใช่ไหม Neuronเราก็สร้าง เราใช้ Thunder Coreซึ่งมันจะทำให้ Class เนี๊ยะมันจะนำให้เราเรียกใช้ Class ให้แบบฝ่างกันได้เออเราก็จะมีของทาง Neuron ตัวหนึ่งLayer แล้วก็ MLP New one ก็คือเราต้องบอกว่ามันมีกี่ input เอิ่ม New one ต้องบอกว่ามีกี่ input แล้วมันก็จะ output ตัวเลขมาค่าหนึ่งใช่ไหม ก็คือก็ต้องเอา weight มาคูณกับ input แล้วก็บวกกับ bias แล้วก็ใส่อะ tanh เนี่ยก็จะ put value มา อันนี้คือ neuron

ส่วน layer layer ก็มีหลาย neuron ก็คือเป็น list เป็นลำดับเป็น list ของ neuron ทีนี้ layer take อะไร layer ก็ต้องมีจำนวน input แล้วก็จำนวน neuron แล้ว output ของมันก็จะเป็น ,listซึ่งมี element เท่ากับจํานวน neuronทีนีส่วน parametersคือ neuron ก็จะมี n inputparameter ก็จะมี n+1ก็มีจํานวน input กับ bias ทีนีมัน ก็จะ listเนี๊ยะเนื้อต่อแต่ W1-Wnรวบกับ Bออกมาเป็น parametersแล้วก็parametersของ layerก็จะเป็น list เหมือนกันของแบบparametersของแต่ละ neuronมาแบบcontact ทีในเกณฑ์มาต่อกันเป็น list dimension เดียว

parameters() คืนอะไร และไม่คืนอะไร

อ๋อ พร้อมวิวเตอร์ไม่คืนอะไรใช่ไหมคือพร้อมวิวเตอร์อะ มันจะคืนแค่คืนแค่ค่าของแต่ตัวมันก็เป็น value ใช่ไหม ของพร้อมวิวเตอร์นะแต่เราจะคืนแค่ dot data เราจะไม่คืนทาง value เพราะมันเปลือง เพราะมันเปลืองหรือเปล่า เปลือง เดี๋ยวพารามิเตอร์มันจะเอาไปใช้ เอ๊ะ Power ตัวมันเอาไปใช้ตอนที่เราจะอัปเดตหรือเปล่า ตอนที่เราอัพอัปเดต ไม่ได้ดิเราต้องคืน Value ป่ะ เอ๊ะ เราเราเอาแค่ Data ก็พอหรือเปล่า เอ้ยหรือว่าต้องเอาทั้ง Value เป็น Object เลย

เพราะตอนที่เราไปอัปเดตตอนที่เราทำ เอ่อ Training แปบนึง Training ตอนที่เราเรียก Backward เอ้ย คือสับสนระหว่าง Training กับ Backward แหละ Backward แล้ว คือไอ function Backward นี่มันแค่มันแค่คำนวณ Gradient น่ะ มันแค่คำนวณ Gradient แต่ว่าตอนที่เอา Gradient มาอัปเดตคือมัน มันคืออยู่ใน Training Loop แล้วมัน Training Loop มันคือ Forward Pass ใช่ไหม คำนวณ Loss Backward Pass คำนวณ Gradient แล้วก็ แล้วก็อัปเดต อันนี้คือ Training Room แต่ว่าไอแค่ Backward อ่ะมันก็แค่มัน มันก็แค่ มันก็แค่คำนวณ Gradient อ่ะ เออเมื่อกี้พูดผิดว่ะ

แล้วที่บอกว่า Backward ทำ 4 อย่างในอันนี้คืออะไรนะ Set Gradient เป็นหนึ่ง Set Gradient เป็นหนึ่ง คำนวณ Gradient ของแต่ละตัวตาม Topological Sort แล้วมันก็เข้าคำนวณ Gradient แล้วก็จบแล้วป่ะ Backward เพราะว่าไออัปเดต Parameter มันทำตอน Training Loop ไม่ใช่ทำตอน Backward ตอน backward แล้วถ้าพี่บอกทำสี่อย่างนี่มันคืออะไรนะ เพราะตอนเราคิดตอนนี้มันมีแค่สองบางสองอย่างป่ะ เช็ก gradient เป็นหนึ่งแล้วก็ เอิ่ม แล้วก็คำนวณ gradient ตามลำดับ topological sort
