Closure คือตอนแรก ถ้าเกิดมันไม่มีตะกร้ากลาง ถ้าเกิดเป็น Global Variable จริง ๆ closure มันคล้าย Global Variable แต่เป็นแค่ Global Variable ใน context ของ function. มันเรียกว่า closure เพราะมันเหมือนมี function ใน function ย่อย. ทุกครั้งที่เรียกมัน จะเก็บ ค่าในตัวแปรหนึ่งในฟังก์ชันใหญ่ คือถ้าเกิดไม่มีฟังก์ชันใหญ่อ่ะมันก็จะเก็บเข้า Global เลยไง แต่เหมือนเราไม่ต้องการ Global เพราะมัน เพราะมันใช้ซ้ำไม่ได้เราก็เลย close Global Variable นั้นน่ะโดยการสร้างฟังก์ชันขอบใหญ่สุดอันนั้นอีกรอบ ก็เลยมันก็เลยเรียกว่า closure ก็ปล่อยซึ่ง Non-Global เข้ามันเหมือนจะต้องข้ามโคลเชียร์ตรงทีเรามีฟังก์ชันในเรามีตัวแปรในฟังก์ชันใช่ไหมเราอยากให้ตัวแปรนานมันมันไม่ลอเข้าอ่ะก็คือสามารถใช้นอกจากฝังชันนานได แล้วมันต้องใช้ตอนไหนกับไม่ต้องใช้ตอนไหนอ่ะ เออเนี่ยเราควรจะเขียนไอ-- ไอ้ฟังก์ชันไอ factorial อะไรอย่างเงี้ยโดยที่ใช้ลอง ลองใช้ non-local หน่อย เพราะปกติเราจะใช้ที่มันเป็นแบบ rec-recursive แบบที่แบบมัน pass value เข้าฟังก์ชันตัวเองอ่ะ ไอ้ตรง recursive วิธีการคิดตอน recursive เนี่ยคือ เรายังสับสนหน่อยแต่ว่าคือตอนนีเรามีแม้มีวิธีกิจใหม่แล้วก็คือก็เท้นท์ทิจะเหมือนส่งแบร์ลู กกลับเข้าไปในฟังก์ชันเดิมอะไรอยเง่ะคือทุกครามทีเราเรียกฟังก์ชันเดิมแล้วก็เก็บไปในเก็บไปในตาก้า กลางในแบสเก็ต กลาง

งานคือประเด็นน

ส่วนข้อสุดท้าย ข้อหก Git add ทำอะไรกับไฟล์จริงๆ คือ add เนี่ย ตอนที่เรา add อะ มันเก็บข้อมูลเนื้อหาของไฟล์ไปด้วย

เพราะงั้นถ้าเกิดเรา add แล้วเราไปแก้ เรา commit เงียบ คือไอนเน่ะมันจะตอนทท์ทท์เรา commit มันจะไม่ได้อัปเดท มันจะไม่ได้อัปเดทไอท์ทททท์เราแก้ไปด้วย เพราะเราไม่ได้ add อีกที

เพราะงานเราก็ต้อง add ก่อน ถ้าเกิดเราแก้นะ เราก็ต้อง add อีกรอบแล้วค่อย commit เพราะงานถ้าเกิด add ไปแล้วแล้วไปแก้แล้ว commit เลยอย่างเงียบ ไอททททท์แก้ไปมันไม่อยู่ใน commit
