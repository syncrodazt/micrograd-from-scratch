คำถามค้าง — ตอบถูก

ไอตัว 84 ตัวมันจะถูกคำนวณใหม่ เป็น Value คนละ object พองั้น grad มันก็เป็นศูนย์อยู่แล้ว

นั่นคือคำตอบทั้งหมด — ตัวกลางไม่ต้องล้างเพราะมันไม่ได้อยู่ให้ล้าง มันตายไปแล้วตั้งแต่รอบก่อน มีแค่ 41 parameter ที่รอดข้ามรอบ จึงมีแค่ 41 ตัวที่สะสมของเก่าได้

(85 ก้อนนั้นเป็นตัวกลางทั้งหมด — นับหลังสร้าง network เสร็จแล้ว)

และตอบคำถามที่ยังไม่ได้ถาม

“ถ้าไม่คำนวณ gradient ของ intermediate ใน layer 2 แล้ว gradient ของ weight ใน layer 1 ก็คำนวณไม่ได้”

ถูก — ตัวกลางไม่ใช่เป้าหมาย แต่เป็นทางผ่านที่ขาดไม่ได้ เราไม่เคยใช้ gradient ของมันเลย แต่ถ้าไม่มี gradient ก็เดินย้อนต่อไม่ได้

ข้อ 1 — สรุปถูก แต่กลไกไม่ใช่อย่างที่คิด

ถ้า x เป็นศูนย์ gradient ของ w ก็เป็นศูนย์

ตั้ง parameter ทุกตัวเป็น 0.0 แล้ววัดว่าใครยังมี gradient เหลืออยู่บ้าง:

output: 0.0

layer 1:   0 จาก 16 parameter มี gradient ไม่เป็นศูนย์    []
layer 2:   0 จาก 20 parameter มี gradient ไม่เป็นศูนย์    []
layer 3:   1 จาก  5 parameter มี gradient ไม่เป็นศูนย์    [4]

ตัวเดียวในทั้ง network ที่ยังมี gradient คือ bias ของ neuron สุดท้าย

เหตุผลไม่ใช่ที่คิดไว้ — ต้องแยกเป็นสามกรณี:

ใครทำไม gradient เป็นศูนย์
weight ของ layer 1 input คือข้อมูลจริง ไม่ใช่ศูนย์ (1.0, −2.0, 3.0) — ที่เป็นศูนย์คือ gradient ที่ไหลลงมาถึงมัน เพราะจะผ่าน layer 2 ได้ต้องคูณกับ weight ของ layer 2 ซึ่งเป็นศูนย์
weight ของ layer สุดท้าย ถูกคูณกับ activation ของชั้นก่อนหน้า ซึ่งคือ tanh(0) = 0
bias ของ neuron สุดท้าย รอด — + ส่ง gradient ต่อเท่าเดิม ไม่ต้องคูณอะไรเลย

ผลคือ network ทั้งก้อนยุบเหลือค่าคงที่ตัวเดียว — เรียนรู้ได้แค่ “ควรตอบเลขอะไรโดยไม่สนใจ input” ซึ่งแย่กว่าที่คิดไว้ เพราะไม่ใช่แค่ “เรียนช้า” แต่คือเรียนไม่ได้เลยตลอดกาล

บทเรียนที่กว้างกว่านั้น: ทางกลับของ gradient ถูกตัดขาดได้ที่จุดใดจุดหนึ่งกลางทาง ไม่จำเป็นต้องเป็นที่ตัว parameter เอง — เป็นรูปแบบเดียวกับ vanishing gradient ในข้อ 2 ต่างกันแค่ข้อ 2 คูณด้วยเลขเล็กมาก ส่วนข้อนี้คูณด้วยศูนย์เป๊ะ

ข้อ 7 — ถูก และไปไกลกว่าที่ถาม

คำตอบไปจบที่ momentum ซึ่งเป็นการเชื่อมโยงที่ดี แต่มีเส้นแบ่งสำคัญ

เรียก backward() ซ้ำโดยไม่ล้างอะไรเลย ดู parameter ตัวเดียวกัน:

รอบ 1   p.grad = +0.565647
รอบ 2   p.grad = +1.131295
รอบ 3   p.grad = +1.696942
รอบ 4   p.grad = +2.262590
รอบ 5   p.grad = +2.828237

โตเป็นเส้นตรง ไม่มีขอบเขต — รอบที่ 100 จะเป็น 56 · รอบที่ 1000 เป็น 565

ลืม zero_gradMomentum
สูตรg₁+g₂+…+g_kv ← βv + g (β ≈ 0.9)
ของเก่าน้ำหนักเท่าเดิมตลอดกาลจางลงแบบเรขาคณิต
ขนาดโตไม่มีที่สิ้นสุดมีเพดานที่ ~g/(1−β)
ผลก้าวใหญ่ขึ้นเรื่อยๆ จนระเบิดก้าวนิ่งขึ้น ผ่านหุบแคบได้ดีขึ้น

สัญชาตญาณถูก — “ทิศทางเก่ายังมีค่า” คือไอเดียเบื้องหลัง momentum จริงๆ
ต่างกันที่ β ตัวเดียวที่ทำให้ของเก่าจางไป · ลืม zero_grad คือ momentum ที่ β = 1 — ซึ่งคือความต่างระหว่างเทคนิคที่ใช้ได้ กับบั๊ก

อีกเส้นที่ต้องแยก

การสะสมภายใน 1 step เป็นสิ่งที่ต้องการ — บวก gradient จากทุกตัวอย่างใน batch
ที่ผิดคือสะสมข้าม step · เส้นแบ่งอยู่ตรง “รอบไหน” ไม่ใช่ “สะสมหรือไม่สะสม”

ข้อ 4 · 5 · 6 — เฉลย

ข้อ 4 · parameters() คืนสำเนา

def parameters(self):
    return [Value(p.data) for p in self.ws + [self.b]]     # คืนสำเนา

p.data -= lr * p.grad จะเขียนลงในสำเนาที่ไม่มีใครใช้ แล้วสำเนานั้นก็ถูกทิ้ง

network ไม่เคยเปลี่ยนเลยสักครั้ง loss นิ่งสนิท ไม่มี error — เทสต์ test_parameters_are_the_real_objects_not_copies มีไว้ดักตัวนี้ (mutation test บอกว่าพัง 10 ข้อ)

ข้อ 5 · Layer ใช้ Neuron ตัวเดียวซ้ำ

n0 = Neuron(nin)
self.neurons = [n0] * nout        # object เดียว ชี้ซ้ำ nout ครั้ง
  • output ทุกตัวเหมือนกันเป๊ะ
  • parameters() คืน parameter ชุดเดิมซ้ำ nout รอบ → ถูก update nout ครั้งต่อ step (learning rate กลายเป็น nout เท่าโดยไม่ตั้งใจ)
  • layer ที่มี 100 neuron มีความสามารถเท่ากับ 1 — อาการเดียวกับ symmetry ในข้อ 1

ข้อ 6 · += แทน -=

gradient ascent — ไต่ขึ้นเขาแทนลงเขา loss เพิ่มทุกรอบจนระเบิด · เทสต์ test_stepping_along_the_gradient_raises_the_output มีไว้ตรึงเครื่องหมายนี้โดยเฉพาะ
