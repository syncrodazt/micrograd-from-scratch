Lesson 01 · 2026-08-08
Value ที่จำที่มาของตัวเองได้

ทำไม float ธรรมดาถึงใช้ทำ autograd ไม่ได้ · node หนึ่งตัวต้องเก็บอะไรบ้าง · operator overloading ที่ทำให้กราฟโผล่มาเองระหว่างคำนวณ

Lesson 02 · 2026-08-08
DAG ไม่ใช่ tree

x*y + x มี x กี่ node · การมาบรรจบกันคือใจกลางของ backprop · การเดินซ้ำที่ระเบิดแบบ exponential · set ที่ไม่มีลำดับ

Lesson 03 · 2026-08-08
Recursion, closure และการเดินกราฟ

กรอบคิด 4 ข้อที่ไม่ต้องไล่การทำงานในหัว · ทำไมเรียกว่า closure · id() ไม่ใช่ hash() · แยกการเดินกราฟออกจากการวาด

Lesson 04 · 2026-08-08

คำถามที่ยังเปิดอยู่

  • การ์ดกันเดินซ้ำควรอยู่บรรทัดไหนของ recursion และควรเช็คว่าอะไร
  • เจอ node ซ้ำแล้วควร return ทันที หรือไม่เก็บแต่เดินลึกต่อ — สองอย่างนี้ให้ผลไม่เหมือนกัน
  • ถ้า node หนึ่งโผล่สองครั้งในลำดับที่ใช้เรียก _backward() gradient จะผิดไปกี่เท่า
  • label ของ node กลางควรตั้งมือ หรือให้สร้างอัตโนมัติจาก data
