### B1. ทำไม Value ต้องจำ _prev กับ _backward
    
<!-- - ตอน forward เราเก็บอะไรไว้บ้าง ทำไมต้องเก็บ -->
ต้องจำ
1. Value ก่อนหน้าใน _prev
2. วิธีคำนวน gradient ย้อนกลับ

ต้องจำ 1 เพราะว่า ตอนที่เราจะทำ back propagation เราต้องมีลำดับnodeของตัวก่อนหน้า เราต้องรู้ว่า c เนี่ยมาจาก a กับ b นะ เราจะได้สร้าง order ในการเรียก _backward ถูก

ต้องจำ 2 เพราะว่า ตอนที่เราเรียก c._backward() เราต้องรู้ว่าจะอัพเดท grad ของ a กับ b ยังไง
ถ้า c = a*b, a.grad += c.grad *b.data, b.grad += c.grad *a.data

<!-- - "graph มันสร้างตัวเองตอน forward" หมายความว่าอะไร -->

### B2. ทำไม gradient ต้อง +=  ไม่ใช่ =
    - node ที่มีลูกหลายตัวคือกรณีไหน
        ลองดูตัวอย่างนี้
            z = x*y+x
        x = Value(-3)
        y = Value(2)
        dz/dz = 1
        dz/dx = y+1 = 3
        dz/dy = x = -3

    - += นี้มาจาก chain rule ตัวไหน (ไม่ใช่เรื่อง Python)
        d(f+g)/dx = df/dx +dg/dx
    - ถ้าใช้ = แล้วมันพังยังไง ตัวเลขไหนผิด
    คือ ถ้าเกิดเรามองอย่างเนียน ซัสเท่ากับ x คูณ y ใช่มะ บวก x คำถามคือ gradient ของ x มันแปลว่าอะไร? Gradient ของ x แปลว่าเราปรับ x แล้ว z มันเปลียนยังไงได้บ้าง? แต่ว่า z เท่ากับ x คูณ y บวก x เพราะฉะนึง ถ้าเกิดเราเปลียน x อะ สิ่งทีมันจะไปต่อ z อะ มันก็คือจากโพธิ x คูณ y เราก็จากโพธ x ใช่ไหม? แต่ว่าถ้าเกิดเราคํานวณเราให้มันเป็นเท่า กับนะ ตอนทีมัน Backward จาก x-y ตอนทีมัน Backward จาก x-y มันก็จะคํานวณ gradient ของ x ว่าคือว่า อันแรกคือ z dot gradient ก็คือ 1 คูณกับ y dot data ก็ค y ก็ค 2. ตอนแรกมัน set gradient ของ x เป็น 2 แล้วมันก็จบ. ถ้าเกิดเป็นเท่าข้ามันจบมันจบที gradient ของ x เข้าสอง เพราะอย่างทิบอก x ส่งผลประสบความสุดกับ z ทั่ง x คูณ y แล้วส่งผลกระทบทิ้มันส่งต่อแสต์ จากแค่ไอ้บวก x เหล่า. มันส่งยังไงเราถ้าเกิดเราไม่ได้บวก เราก็จะไม่ได้บวกตรงนั้นไป เพราะว่า ds เป็น x จริงๆ มันคือ y + 1 ไงไอ y เหล่า มันคือผลกระทบทิ้เราทำต่อ ทำจาก x คูณ y แล้วบวก 1 อ่ะ คือผลกระทบทิ้เกิดจากไอพฤตบวก x นี่แหละ. 

    โอเค จากตัวอย่างเมื่อกี้ที่นายให้ว่า z = x tanh(x) เราเห็นละ คือปัญหามันคือว่า ถ้าเกิดเรามีตัวแปรสุดท้ายคือ z ใช่ไหม แล้ว x ของเราอ่ะมันส่งผลกับ z หลายทางอ่ะ มันส่งผลกับหลายทางอ่ะ มันก็จะมีหลายโหนดเพื่อ. โหนดที่เราเรียก Backward อ่ะ มันก็จะมีหลายโหนดที่เราเรียก Backward ครั้งนึง. มันจะอัปเดตทั้ง Child กับ Parent โหนด ลูกของโหนด ลูกของมันทั้งหมดใช่ไหมล่ะ?

แต่ทีนี้ ถ้าเกิดเราแบบเหมือนมีกิ่งสองกิ่ง แล้วกิ่งหนึ่งก็สุดท้ายก็เป็น x อีกกิ่งหนึ่งสุดท้ายก็เป็น x เพราะงั้นตอนที่เราเอาอัปเดตเรียก Backward อ่ะ มันจะเดี๋ยวมันจะไปใส่ค่าของ Value ตัวเดิมอ่ะ แต่มันจะสองครั้ง. ซึ่งเราสองครั้งนั้นเราต้องเอามาบวกกันมันถึงจะได้ Gradient จริงๆ.

### B3. ทำไมต้อง topological order
    - ถ้าเรียกตามลำดับที่สร้าง node จะเกิดอะไร
        gradient จะผิด
    - invariant คืออะไร (พูดเป็นประโยคเดียวให้ได้)
        ?อื้อมม อินแวรียนท์ของอะไรก่อน อินแวรียนท์ของอะไรคือเราเข้าใจอินแวรียนท์ คือไม่ว่าแบบคือการทิ้งมันไม่เปล่าเปล่าง คือมันคงสภาพเดินอยุ่ ไม่ว่าแบบอะไรมันจะเปล่าเปล่ายังไ่ แต่คำถามคุณเกษตรอินแวรียนท์ของอะไรของ Order เหรอคือเหมือน Topological Order อะ มันก็ไม่ได้มีเค้า Order เดีย มันก็มีหลาย order แต่ว่า แต่มันต้องเป็น topological order แบบไหนก็ได้ แต่มันต้องเป็น topological แล้ว ผลลัพธ์ที่ได้มันจะเหมือนกัน.
    อ๋อ เขาบอกว่า gradient เขาคำนวณแล้วคำนวณได้ อ่ะ มัน invariant ก็ต่อเมื่อ order ที่เราใช้เป็น topological order. 

    - ทำไม post-order DFS + reversed ถึงให้ลำดับนั้น
        เพราะว่ามันไล่กิ่งให้ครบก่อน การที่มันไล่กิ่งให้ครบ พอเรา Reverse แล้ว ก็แปลว่า ก่อนทีเราจะไป Layer ใหม่ เราต้องไปกิ่งใน Layer นะ เข้มันครบครบแล้ว ซึ่งมันก็คือตรงกับกฎของตอนทีเราคํานวณเกรดียันว่าเวลาจะคํานวณเกรดียัน เราต้องคํานวณเกรดียันของ Parent ของโน้ตน้ํานให้หมดก่อน เพราะไม่งานเกรดียันทิศเราคํานวณ ของโหนดนั้นน่ะมันจะผิด ถ้าเกิดเรายังเราคำนวณไม่หมดอ่ะ
